A small bridge to Tally

Ask Tally for business data without carrying the XML plumbing everywhere.

Choose a supported query, provide the company name, and get Tally's response as XML. Use the exact same query from a JavaScript application or from a shell command.

The story in one minute

One query model. Two entrypoints.

The public API is an allowlist of useful Tally queries. Tally Simple turns a selected path and company into the standard XML request, sends it to the configured endpoint, and returns the response unchanged.

1

Choose

Select a query such as masters.units.fetch.

2

Request

Give the company name. The client builds and escapes the XML request.

3

Receive

Read, save, pipe, or parse the raw XML returned by Tally.

Get started

Install once. Use it where the work happens.

Node.js 20.10 or newer and a Tally HTTP endpoint are the only requirements.

1 / Install

Add the package

npm install tally-simple
2 / JavaScript

Call a public path

import tally from "tally-simple";

const xml = await tally.masters.units.fetch("Mani9");
console.log(xml);
3 / Shell

Run the same query

npx tally-simple \
  masters.units.fetch \
  --company Mani9
PowerShell

Use environment variables

$env:TALLY_COMPANY = "Mani9"
$env:TALLY_URL = "http://localhost:9000"
npx tally-simple masters.units.fetch

What happens next

Small boundaries keep the package predictable.

Raw means flexible. Tally Simple returns XML text instead of choosing a parser or object shape for your application. That keeps the package useful for inspection, files, pipelines, and whichever XML tooling you already use.

Validation before the request

Company names must be non-empty. The value is trimmed and XML-escaped before it enters the request envelope.

Configuration when the default is not enough

createTallyClient() accepts a URL, method, headers, timeout, and fetch-compatible adapter. The default URL is http://localhost:9000.

Errors that remain useful

HTTP errors include the status and response body. CLI errors go to stderr and return a non-zero exit status.
